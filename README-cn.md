# Formula Library - Obsidian Plugin

中文文档 | [English Doc](README.md)

Core 公式转换需要 Formula Library **1.6.0 及以上版本**。

为 Obsidian 提供可视化 LaTeX 编辑、本地公式格式转换、可搜索的公式库、自定义参数模板、Mermaid 绘图和参数驱动的函数绘图。

Formula Library 帮助你在笔记中创建、查找和复用数学表达式。插件结合 MathLive 可视化编辑器、**19 个分类共 2,216 条内置公式**、智能搜索，以及可独立开启和关闭的内置库与个人库。

你可以创建参数化模板、保存命名预设、把粘贴的表格转换成矩阵，并通过参数控件实时探索函数。Mermaid 编辑器提供 **11 种绘图模板**，流程图和状态图支持可视化编辑，所有图型均支持预览与 SVG 导出。

收藏、置顶、最近使用、可搜索的说明、完整备份和草稿恢复帮助你管理个人内容；响应式布局、可调整字号与密度，以及中英文界面适配不同设备和使用习惯。

## 功能

- **MathLive 可视化编辑器**：WYSIWYG 公式编辑，实时预览 + 虚拟键盘
- **设置分组与工具开关**：常规、界面、工具、公式库、备份分组；可独立关闭格式转换、参数模板、矩阵粘贴、保存到个人库、函数绘图与 Mermaid 入口，保留已有内容。
- **本地公式格式转换**：内置精简 Core Worker，处理单个 LaTeX、Typst、MathML、OMML 公式；默认尽力转换，可手动选择严格模式，两者都需检查结果并确认使用。
- **2216 条公式**：19 个分类，新增 95 条算法、图论、信息论、机器学习、图形学、信号和数值计算公式
- **智能搜索**：拼音首字母、LaTeX 命令别名、英文单词匹配、缩写匹配（如 `lt` → less than）、模糊匹配；精确名称与精确命令优先，显示命中总数并可继续加载
- **公式库控制**：内置公式库总开关 + 19 个分类独立开关 + 一键全部开启/关闭；即使没有 `formulas/` 文件夹也能在设置中管理分类，关闭只影响是否使用，不删除收藏、置顶和历史
- **内置与自定义分离**：自定义公式库独立加载与开关，关闭内置库后仍可使用自定义库和公式编辑器，空库不会自动重新开启内置库
- **自定义公式可视化管理**：在设置中新增、编辑、删除分类与公式，支持导入（JSON / 文本行）与导出（纯文本 / JSON 备份），保存前校验 LaTeX 与重复项
- **参数化公式模板**：19 个常用模板（一元二次求根、抛物线、顶点式、直线、求和/连乘、定积分、极限、导数、偏导、二项式、二阶行列式、正态分布、泰勒展开、匀加速、动能、牛顿第二定律等），用命名参数代替零散占位符；填写后实时预览，每个模板可保存最多 20 组参数预设，一键插入笔记或填入编辑器
- **设置即时生效**：修改公式来源、分类、字体、密度、排序、结果上限后，侧栏和已打开的编辑器立即刷新
- **个人公式库**：在公式编辑器里把当前公式直接保存到自定义库，填写名称、标签和说明；标签与说明都能被搜索，JSON 备份会一并保留
- **公式详情**：从公式操作菜单查看完整 LaTeX 与说明；个人条目可补充变量含义、单位、适用条件和来源，这些字段能被搜索并随 JSON 备份保留。
- **完整备份与恢复**：一个版本化 JSON 文件包含个人公式分类、模板、参数/绘图预设、收藏、置顶、历史、草稿和设置；恢复前校验和预览，并选择冲突处理策略。
- **未完成草稿保护**：公式与函数绘图提供明确的恢复/丢弃操作，Mermaid 草稿继续保留；可在设置中关闭草稿保存。
- **使用频率排序**：常用公式自动排在前面——搜索结果和分类列表按插入次数排序
- **公式控制**：支持收藏、置顶、最近使用、隐藏、复制，以及智能/次数/最近/名称排序、卡片密度和结果上限
- **Mermaid 绘图**：11 种模板；流程图和状态图支持节点/连线可视化编辑，所有图型支持源码、居中预览和 Markdown 插入；可直接编辑笔记里已有的 ` ```mermaid ` 代码块（原地替换），预览支持缩放/平移/适配与导出 SVG；切到可视化前会检测不支持的语法、保留源码，并提供撤销/重做、原稿还原和关闭弹窗后的草稿恢复
- **可配置快捷键**：自定义分数、根号、上标、下标快捷键（默认未绑定）
- **矩阵模板**：支持 cases、matrix、bmatrix、pmatrix、jacobian、hessian、identity、diagonal、augmented 等
- **矩阵数据粘贴**：从 Excel、表格或文本粘贴数据，自动识别制表符、逗号、分号、竖线和空格分隔，生成 matrix / bmatrix / pmatrix / vmatrix / Vmatrix / array / cases / aligned 等 LaTeX；支持转置、增删行列、把文本单元格包成 `\text{}`、实时预览并插入笔记
- **函数绘图**：输入 `y = f(x)` 表达式即可绘图，支持隐式乘法、省略括号的函数写法与常用函数，除 `x` 外的字母自动变成滑块，也可写自己的函数定义与每曲线局部常量；可叠加多条曲线、自动纵轴范围与跟随主题配色，并能插入 SVG、保存图片嵌入、复制或下载 SVG
- **Visual / Source 模式**：可视化编辑与 LaTeX 源码切换
- **编辑已有公式**：光标放在 `$...$` 或 `$$...$$` 内，运行命令即可编辑
- **侧边栏快速插入**：左侧边栏直接点击插入公式
- **分类下拉框**：分类选择器改为下拉菜单，侧边栏更紧凑
- **设置页面**：语言、插入格式、编辑器模式、快捷键、字体、密度、排序、结果上限、LaTeX 标签、公式库来源与分类开关、自定义公式管理
- **可扩展公式文件夹**：在 `formulas/` 中放入 JSON 文件即可添加内置库分类；也可在设置中指定自定义公式文件夹（相对 Vault 根目录），其分类与内置分类分开管理
- **中英文双语**：跟随 Obsidian 语言设置自动切换

## 安装

### 手动安装

1. 从同一个 [Release](https://github.com/strangelion/obsidian-formula-library/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在 Vault 中创建 `.obsidian/plugins/formula-library/`，将这三个文件放入其中。
3. 在 **设置 → 社区插件** 中启用 Formula Library。
4. 可选：在 **设置 → 快捷键** 中分配快捷键。

安装后的插件不需要 Node.js、npm、`src/`、`node_modules/` 或额外的 `formulas/` 文件夹。

### BRAT 安装
1. 在 Obsidian 中安装 BRAT 插件
2. 打开 BRAT 设置，点击 "Add Beta plugin"
3. 输入仓库地址：`strangelion/obsidian-formula-library`
4. 安装后重启 Obsidian

## 使用

### 公式编辑器
- **命令面板**：`Ctrl+P` → "Open Formula Editor"
- **侧边栏图标**：点击左侧 Σ 图标
- 弹窗打开后，右侧选择公式分类，点击公式插入到编辑器
- 修改设置（字体、密度、排序、分类开关等）后无需重开弹窗，右侧列表会自动刷新
- 工具栏的 **参数模板** 按钮可打开参数化模板弹窗，把填好参数的公式直接填入编辑器
- 工具栏的 **矩阵粘贴** 按钮可打开矩阵数据粘贴弹窗，把粘贴的表格数据转成矩阵并填入编辑器
- 工具栏的 **函数绘图** 按钮可打开函数绘图弹窗，输入表达式后把绘制的图像插入笔记
- 工具栏的 **保存到我的公式** 按钮可把当前公式保存到个人公式库（见下文），填写名称、标签和说明
- 点击 **插入**（或 `Shift+Enter`）将公式写入笔记
- 关闭时未完成的公式会保留为草稿。在相同编辑上下文中重新打开后，可选择 **恢复草稿** 或 **丢弃草稿**；草稿不会自动覆盖当前公式。输入短暂停顿后和关闭窗口时都会保存。

### 参数化公式模板

- **我的模板**：点击“新建模板”或“复制为我的模板”，自定义名称、分类、LaTeX、参数显示名和默认值；例如 `y = {{a}} \cdot x + {{b}}`。参数名须以英文字母开头，仅含字母、数字和下划线。模板支持编辑、二次确认删除与参数预设，保存在插件设置中；内置模板保持只读。
- 新建模板未填写名称时也会预览公式；只有保存时才要求名称。预览按默认值生成，乘法请显式使用 `\cdot`，避免数字替换后连写。

- **命令面板**：`Ctrl+P` → "Insert Parameterized Formula"；也可在公式编辑器工具栏点击 **参数模板**，把结果填入编辑器
- 选择模板后填写命名参数，预览与生成的 LaTeX 会随输入实时更新
- 参数值可以是普通数字，也可以是 LaTeX（`\frac{1}{2}`、`\sigma`、`(-3)`）；留空则保留模板默认值
- 以 `-` 开头的值会自动加括号，因此 `-3` 在幂、乘积和减号后依然正确
- **参数预设**：每个模板可保存、应用、删除最多 20 组参数组合，重启后仍然保留

### 个人公式库
- 在公式编辑器工具栏点击 **保存到我的公式**，把当前公式（含可视化编辑器里的内容）保存到自定义库
- 填写名称、标签和说明：标签用空格或逗号分隔（如 `代数 考试`），说明可以写变量含义、适用条件或常见变形
- 可以保存到已有分类，也可以直接填写新分类名称，插件会自动创建
- 同一个公式再次保存会**更新原来那一条**，弹窗会自动带出已保存的名称、标签和说明
- 标签和说明都能被搜索：输入 `#代数` 或标签片段即可命中，说明中的关键词同样可搜
- 在公式操作菜单中打开 **公式详情**，查看完整源码与说明。保存到个人库或在自定义管理器中编辑时，可展开 **变量、单位、条件与来源** 添加结构化说明；内置条目保持只读，需要注释时保存一份个人副本。
- 没有配置自定义公式文件夹时，首次保存会自动使用 Vault 根目录的 `my-formulas/`，并在设置中记为自定义公式路径

### 矩阵数据粘贴
- **命令面板**：`Ctrl+P` → "Paste Matrix Data"；也可在公式编辑器工具栏点击 **矩阵粘贴**
- 从 Excel、表格或任意文本粘贴数据：自动识别制表符、逗号、分号、竖线和空格分隔，短行自动补齐到最宽一行
- 可切换环境：matrix、bmatrix、pmatrix、vmatrix、Vmatrix、array、cases、aligned；两列的 aligned 会输出 `左边 & = 右边` 的对齐公式
- **转置** 与 **增删行列** 按钮直接编辑网格，改动会写回文本框，预览与尺寸随输入实时更新
- 勾选 **文本单元格包在 `\text{}` 中**，非 ASCII 文本或含空格的单元格会转成 `\text{...}`；数字、ASCII 变量和已经是 LaTeX 的内容保持原样
- 支持 **填入编辑器**、**插入到笔记** 与 **复制 LaTeX**

### 函数绘图
- **命令面板**：`Ctrl+P` → "Plot Function"；也可在公式编辑器工具栏点击 **函数绘图**
- 输入表达式绘制 `y = f(x)`：支持 `+ - * / ^`、括号、隐式乘法（`2x`、`3(x+1)`、`x sin(x)`），以及 sin、cos、tan、ln、log10、sqrt、abs、min/max、pow 等常用函数和 `pi`、`e` 常量；省略括号的写法同样可用（`sinx` 等价于 `sin(x)`，`x sinx` 等价于 `x sin(x)`），此时 `sin2x` 表示 `sin(2) · x`，需要 `sin(2x)` 请写括号；用反引号包住的名字（`` `sinx` ``）按普通变量处理
- 除 `x` 与已知常量外的自由变量会自动生成滑块，初始范围为 -10 到 10、步长 0.1。可直接输入精确值，或展开 **范围与步长** 分别设置最小值、最大值和步长；范围无效、数值越界或步长非正时暂停导出，修正后恢复。
- **绘图预设**：最多保存 50 个命名配置，包含曲线、局部常量、函数定义、坐标范围、主题、参数值与范围/步长；在绘图窗口中选择应用或删除。保存变体时请使用新名称。
- 可添加多条曲线叠加显示，每条曲线有独立颜色与图例；`x`/`y` 范围可手动设置，勾选 **自动 y** 则由采样分位数自动确定纵轴范围
- **函数定义**：在弹窗顶部的输入框里每行写一个 `f(x) = x^2 + a`，其后的定义与曲线都能调用；定义里的自由变量（如 `a`）自动成为滑块，参数名在函数内部遮蔽横轴 `x`。递归、前向引用、参数重名或与内置函数同名都会被拒绝，并提示所在行号
- **局部常量**：每条曲线右侧可写 `a=2, b=a+1`，让同一个字母在不同曲线里取不同值；与滑块同名时以局部常量为准，且不再为该曲线生成同名滑块
- 主题可选 **跟随主题**（内联插入的 SVG 使用 `currentColor`，随笔记深浅色变化）、浅色或深色；**复制、下载或保存为图片时会按当前主题写入固定颜色与底色**（独立 SVG 文件无法继承笔记主题，切换主题后需要重新导出）
- 输出方式：**插入 SVG**（直接把矢量标记插入笔记）、**保存图片并嵌入**（写入图片文件夹并插入 `![[...]]` 嵌入）、**复制 SVG**、**下载 SVG**；图片文件夹默认为 `plots`
- 新插入笔记的图会在相邻 HTML 注释中保存配置。把光标放在图的标记块或图片引用内，运行 **Edit Function Plot at Cursor** 重新打开；**插入 SVG** 会原地更新该块，如果编辑过程中笔记内容发生变化，请重新打开后再更新。**保存图片并嵌入** 则创建新图片并插入新引用。要继续编辑，请保留配置注释。
- 旧图没有配置元数据，无法可靠还原表达式；复制/下载的 SVG 和笔记中的图都是静态图像，不带实时滑块。参数交互发生在绘图编辑器内。
- 重新打开时，未完成绘图可 **恢复草稿** 或 **丢弃草稿**。设置中的 **保留未完成草稿** 同时控制公式、函数绘图与 Mermaid 草稿。

### Mermaid 绘图编辑器
- **命令面板**：`Ctrl+P` → "Open Mermaid Diagram Editor"
- **编辑已有的图**：把光标放在 ` ```mermaid ` 代码块内，运行 "Edit Mermaid Diagram at Cursor"，或使用编辑器右键菜单的 **编辑 Mermaid 绘图**；弹窗会打开该块的源码，保存时**原地替换**而不是追加新块
- **预览导航**：预览区上方提供 `−` / `+` / 百分比 / `100%` / **适配**；在预览区按住拖动可平移，`Ctrl`/`⌘` + 滚轮可缩放
- **导出 SVG**：工具栏的 **导出 SVG** 按钮把当前预览保存为独立的矢量文件
- 流程图和状态图可在 **可视化 / 源码** 间切换，直接增删节点、连线并修改方向、形状和文字
- 内置流程图、思维导图、时序图、状态图、类图、ER 图、甘特图、时间线、饼图、象限图和 Git 分支图模板；编辑已有块时会根据源码自动识别模板
- 如果已安装 Excalidraw，工具栏会显示快捷入口，用于自由手绘和形状拖拽
- 点击 **插入绘图**（或 `Shift+Enter`）插入原生 Mermaid 代码块

### 侧边栏快速插入
- 点击 Σ 图标切换侧边栏
- 用下拉框切换分类（自定义库的分类会标注“自定义”）
- 搜索框支持拼音首字母（`fs` → 分数）、LaTeX 命令（`frac`）、英文单词和模糊匹配，结果按匹配度排序
- 搜索时显示“匹配 N 条 · 已显示 M 条”，点击 **显示更多** 继续加载，后面的分类不会被截断
- 点击 ☆ 收藏公式，点击 ★ 取消收藏
- 点击公式直接插入到当前光标位置
- 搜索框中用 **上/下方向键** 选择已显示的结果，按 **Enter** 插入；收藏与操作按钮支持 **Enter/空格**，不会误触外层公式插入。**Escape** 清除键盘选择。
- 每个分类内常用公式自动排在前面

### 备份与恢复

进入 **设置 → Formula Library → 备份与恢复 → 打开备份管理**，或在命令面板运行 **Manage Formula Library Backups**。

1. 点击 **下载完整备份** 保存版本化 JSON 文件，包含已关闭的个人分类、模板、预设、收藏、置顶、隐藏/最近公式、使用次数、草稿和已知插件设置。内置公式数据及已保存的图片文件不重复打包。
2. 恢复时选择 JSON 文件（最大 10 MB）或粘贴内容。选择 **冲突时保留现有内容** 或 **冲突时使用备份内容**；公式按分类内相同 LaTeX 匹配，模板按其标识匹配，预设按名称匹配。
3. 可选恢复界面和分类设置。不会导入文件夹路径：个人公式写入当前配置的文件夹；尚未配置时使用 `my-formulas`。预览会显示目标位置。
4. 点击 **检查并预览**，核对摘要后再 **确认恢复**。修改备份内容或选项后，必须重新检查。

恢复采用追加合并，未匹配的现有条目和分类始终保留。写入前校验并读取目标文件；写入失败时尝试恢复原始文件字节和设置，回滚不完整会明确报告。大规模修改前建议先备份；插件备份不能代替整个 Vault 的备份。

原有个人公式库 JSON/文本导入导出仍在 **管理自定义公式** 中可用。完整备份与旧格式使用各自的导入窗口；迁移模板、预设和设置请使用完整备份。

### 编辑已有公式
- 光标放在 `$...$` 或 `$$...$$` 内
- 运行命令 "Edit Formula at Cursor"
- 修改后点击 **更新**

## 自定义公式

公式数据分为两部分：**内置库**（插件目录的 `formulas/`，没有时使用内置数据）和**自定义库**（设置中指定的文件夹，相对 Vault 根目录）。两者独立加载、独立开关：关闭内置库后仍可使用自定义库和公式编辑器。

### 可视化编辑（推荐）

在 设置 → Formula Library → **管理自定义公式** 中可以直接：

- **新建分类**：填写名称即可，分类 ID 自动生成
- **新增 / 编辑公式**：填写名称、英文名（可选）、LaTeX、标签和说明；保存前检查空值、`$` 定界符、花括号配对以及与其他公式重复
- **导入**：粘贴 JSON 数组、JSON 备份，或每行 `名称<TAB>LaTeX`（支持 `#` / `//` 注释）
- **导出**：导出纯文本或 JSON 备份，可复制到剪贴板或下载为文件
- **删除**：删除单条公式或整个分类（分类文件、`_index.json` 顺序和分类开关会一并清理）

只修改分类显示名时，文件里的其他字段（如 `structures`）和手工编辑的内容都会保留。

下面的手工编辑方式仍然有效，适合批量维护或版本管理。

公式数据存储在插件目录的 `formulas/` 文件夹中，每个分类一个 JSON 文件。

> **BRAT / 社区插件兼容性**：内置公式数据和运行依赖都打包在 `main.js` 中。安装只需 `main.js`、`manifest.json` 和 `styles.css`；`formulas/` 是可选的开发用数据，不需要额外安装。

### 文件结构

```
formulas/
  _index.json          # 分类排序（可选，不存在则自动发现）
  _strings.json        # UI 翻译文本
  greek.json           # 希腊字母
  structures.json      # 结构
  analysis.json        # 分析
  ...                  # 其他分类
```

### 添加新公式到已有分类

编辑对应分类的 JSON 文件，在 `items` 数组中添加新公式：

```json
{
  "id": "greek",
  "structures": false,
  "items": [
    ["α", "\\alpha"],
    ["β", "\\beta"],
    ["自定义公式", "\\mycommand{#?}", "Custom Formula"]
  ]
}
```

### 添加新分类

1. 在 `formulas/` 目录下创建新的 JSON 文件（如 `mycategory.json`）：

```json
{
  "id": "mycategory",
  "structures": false,
  "items": [
    ["公式名称", "\\latex{code}", "English Name"]
  ]
}
```

2. 在 `_index.json` 的 `order` 数组中添加新分类的 ID：

```json
{
  "order": ["greek", "structures", "...", "mycategory"]
}
```

> 如果 `_index.json` 不存在或不包含新分类 ID，插件会自动发现并按字母顺序加载。

### 公式格式

每个公式是数组格式：`[中文标签, LaTeX 代码, 英文标签（可选）]`

- **简单公式**：`["α", "\\alpha"]`
- **带英文标签**：`["分数", "\\frac{#?}{#?}", "Fraction"]`
- **分段标记**：`{"section": "分节标题", "sectionEn": "Section Title"}`
- **矩阵模板**：`["矩阵", "matrix:matrix", "Matrix"]`（前缀 `matrix:` 触发模板）
- **个人公式库元数据**：`["名称", "\\latex", "英文名", {"tags": ["代数"], "note": "说明"}]`（第 4 项可选，仅自定义库使用；标签在列表中显示为 `#标签`）
- 元数据还可包含纯文本字段 `variables`（变量）、`units`（单位）、`conditions`（条件）和 `reference`（来源），在公式详情中展示，并参与搜索和 JSON 备份。

### 公式库字号

编辑器右侧和侧栏中的公式名称、源码标签及控件默认跟随 **设置 → 外观 → 字体大小**。需要独立调整时，进入 **设置 → Formula Library → 界面**，关闭 **跟随 Obsidian 字号**，再调整 **公式库字体大小**（14–32 px）。已打开的公式库会即时更新；**预览字体大小**仍只控制 MathLive 编辑区。

### 设置分组与工具开关

设置页分为 **常规、界面、工具、公式库、备份**，可点击分组或用方向键、Home/End 切换；刷新设置时保留当前分组。

**工具** 中可分别开启/关闭格式转换、参数模板、矩阵数据粘贴、保存到我的公式、函数绘图和 Mermaid 绘图，默认全部开启。关闭后立即隐藏相关编辑器/侧栏按钮，并使对应命令不可用；快捷键绑定、公式、模板、预设、草稿和笔记中的绘图均保留。关闭格式转换还会停止任务并释放引擎。所有附加工具关闭后，普通公式编辑仍可使用。

开关控制入口，不会减小安装文件。编辑器保存按钮关闭后，**公式库** 分组中的个人库管理仍可使用。完整备份包含工具偏好；恢复时需勾选恢复界面和分类设置，才会应用这些偏好。

## 格式支持与限制

现有 LaTeX 编辑与插入、Mermaid 绘图编辑和 SVG 输出仍独立于 Core。MathLive/Obsidian 渲染不等于通用 TeX 编译器，也不保证保留任意自定义宏。

### 转换单个公式

1. 从命令面板运行 **Convert Formula Format**，或点击公式编辑器的 **格式转换**。
2. 选择 **来源格式** 并粘贴一个公式。可选 LaTeX、Typst、MathML、OMML，不是完整文档或 Office 剪贴板对象。
3. 选择 **LaTeX（裸公式）**、Typst、MathML 或 OMML 输出。可用性由内置 Core 的实际能力矩阵决定。
4. 默认 **尽力转换**，常用路线不必每次切换模式，请留意界面上的语法/样式损失提示。需要时可手动选择 **严格**，它仅支持有限的 LaTeX → OMML 子集；选中严格后失败不会自动降级。
5. 点击 **转换**，检查文本、诊断及 LaTeX 的 MathJax 预览。**复制结果** 复制纯文本；**打开公式编辑器** 打开独立公式草稿；**填入当前编辑器** 插入已有草稿。不会直接写入或替换笔记，最终仍需使用编辑器的插入/更新确认。

原始内容始终保留在窗口中。修改原文/选项会清除旧结果；取消、关闭、超时或失败不会替换原文。加载失败时可 **重试引擎**，普通 LaTeX 编辑仍可使用。引擎随插件内置，无需另行下载 Core、安装 Node、下载识别模型或连接转换服务器。输入上限为 64 KiB UTF-8，序列化结果上限为 256 KiB，排队与执行总等待上限为 30 秒。

尽力转换可能丢失语法或样式。两种模式都不保证恢复作者原始源码、外观一致、完整往返，或全部 Core 语法都能被 MathLive/MathJax 渲染。LaTeX 预览失败时禁止填入编辑器，但文本仍可检查/复制。OMML 是 XML，不等于 Word 原生剪贴板或 OLE 对象；未开放 AsciiMath、UnicodeMath、MTEF，也不包含 OCR、PDF/DOCX/PPTX 生成、TikZ 编译或全 Vault 转换。

已在本机 Windows Obsidian 验证加载、转换、预览与控件布局。**Android/iOS 尚未进行真机转换验收**，桌面竖屏模拟不代表手机端通过。详见 [接入与平台覆盖](docs/CORE-INTEGRATION.md)。

## 数据与隐私

个人公式保存在指定的 Vault 文件夹中；设置、模板、预设和草稿使用 Obsidian 插件数据存储，绘图图片写入配置的图片文件夹。备份可能包含私人公式、说明、草稿和路径，请妥善保管。

复制/粘贴功能会访问剪贴板，因此自动审核可能列出“Clipboard Access”。新增的备份和绘图功能没有加入后台剪贴板监控或外部服务；扫描结果中的“不可用”并不代表安全保证。

公式编辑和绘图依赖 MathLive 与 Obsidian 的渲染环境，不需要额外账户或绘图服务器，但不应据此宣称所有宿主或渲染资源绝对不访问网络。

Core 在本地独立 Worker 中处理你提供的文本，不扫描 Vault、不把转换输入写入设置、不监控剪贴板、不下载 OCR 模型，也不上传诊断。仅明确复制时访问剪贴板；宿主和其他插件的网络行为不属于此引擎的边界。
